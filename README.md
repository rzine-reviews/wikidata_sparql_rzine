**Résumé :**   
Cet article est le fruit d’un dialogue interdisciplinaire entre membres du [GT Notebook](https://gt-notebook.gitpages.huma-num.fr/site_quarto/) initié dans le cadre d’un atelier proposé à la Journée d’études normande sur les données de la recherche qui s’est déroulée en décembre 2021. L’association de plusieurs compétences et disciplines a abouti à ce document. Il présente une analyse exploratoire reproductible de données ouvertes et liées d’un fragment de graphe Wikidata, interrogeables sous la forme de triplets RDF. Les enjeux d’un tel processus inter-disciplinaire sont esquissés en conclusion.

Pour la consulter, cliquez [**ici**]( https://rzine-reviews.github.io/wikidata_sparql_rzine/)
